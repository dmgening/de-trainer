# Отчёт приёмки MVP

**Дата:** 2026-11-02 · **Сборка:** ветка `feat/mvp`, до деплоя. Критерии — §12 PRD.

**Как проверялось.**

- Автотесты: 115 тестов в трёх пакетах.
  - `core`: 63 — проверка ответа, вывод состояния, сборка тренировки, публикация.
  - `fixtures`: 2.
  - `server`: 50 — настоящий Hono в процессе, SQLite, каталог файлов, подписанные JWT; API не мокается.
- Вручную: собранный сервер на `localhost:8080`, Chrome (встроенный браузер Claude) с эмуляцией телефона 375×812. Вход — через dev-замену Access.
- Не проверялись: настоящий Cloudflare Access, iOS Safari и Android, Playwright E2E.

## Что осталось

- **A13 и вход в установленной PWA на iOS** — главный риск, проверяется после деплоя по протоколу в `docs/ops.md`.
- **Настоящий Cloudflare Access** (Google и сервисный токен) — после деплоя.
- **Playwright E2E** из спецификации не написаны. Сценарии пройдены вручную, логика покрыта unit- и интеграционными тестами.
- **Ежедневные выгрузки и `rclone` картинок** не настроены. Litestream копирует только SQLite; картинки восстанавливаются повторной загрузкой Номиром.
- **OpenAPI-файл** не сгенерирован: вместо него JSON Schema по `/agent/v1/schema/*` и `docs/agent-api.md`.
